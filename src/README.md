1. Project Name

FitLog

2. Short Description

FitLog is a modern workout library and planning web application where users can explore workouts, view workout details, save their favorite workouts, and create a personalized workout plan.

3. Technologies Used
Next.js
React
TypeScript
Tailwind CSS
DaisyUI
React Icons
Recharts
4. 5 Key Features
Practice Library
Users can browse and explore different workouts with details such as duration, calories, rating, and difficulty level.
practice Details
Users can view detailed information about individual workouts before adding them to their plan.
My Plan
Users can add workouts to their personal workout plan and manage their selected exercises.
Save Workouts
Users can save their favorite workouts for quick access later.
Workout Progress & Statistics
Users can view workout-related statistics and track information through an interactive chart-based interface.
